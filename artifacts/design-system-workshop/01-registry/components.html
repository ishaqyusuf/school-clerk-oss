01 — School Clerk design system · shadcn/ui

Registry

The school's register, beautifully kept.

Registry treats School Clerk as the school's own record book: ivory paper, evergreen ink, and a seal-gold mark for whatever is current or chosen. Rows are ruled rather than boxed, a status reads as a dot and a word, and page titles are set in Fraunces so every screen reads like an entry in a well-kept register. It is calm on purpose — the bursar and the registrar live in it all day — and the full module list stays visible in the evergreen frame, so nobody hunts for a page behind an icon.

02 — Foundations

Colour

Ivory paper, evergreen ink, seal gold. Each panel below is themed by its own scope, so light and dark sit side by side whichever theme the page is in. Gold is a mark — active rule, progress, seal, focus accent — and never body text on ivory; use --highlight-ink when gold has to be read.

11 — Patterns

Do & don't

Six rules that keep Registry from drifting back to the old monochrome dashboard.

1

Do keep every module visible as a grouped list in the evergreen frame, with the term card at the foot.

Don't hide navigation in an icon rail that only opens on hover.

2

Do separate rows and stats with hairline rules and a strong rule on top.

Don't box every row, draw vertical gridlines or put KPIs in four floating cards.

3

Do show status as a coloured dot followed by a word.

Don't use filled square badges or colour-only signals in tables.

4

Do set page, sheet and dialog titles in Fraunces, and figures that deserve a pause.

Don't use the serif for controls, table cells or form labels.

5

Do use seal gold only as a mark: active rule, progress, seal, count, focus accent.

Don't fill buttons with gold or set body text in it on ivory — use --highlight-ink.

6

Do write at 13.5–14px in evergreen ink with tabular numbers and plain verbs.

Don't fall back to small grey text on white, square avatars and monochrome everything.
